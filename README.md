# Elias Portfolio

Persoenliche Portfolio-Webseite von Elias "TheFutureGuy" Ivanov.

Die Seite zeigt Projekte, Skills, Discord Presence, Spotify-Aktivitaet und Steam-Daten. Gebaut mit React, TypeScript, Vite und einer Vercel API Route fuer Steam.

## Features

- Moderner Portfolio-Startscreen
- Discord Status und Spotify-Anzeige ueber Lanyard
- Steam Profil, aktuelles Spiel und Spieleliste
- Projektkarten fuer Minecraft Plugins und GTA RP
- Skills-, Ueber-mich- und Kontaktbereich
- Responsive Design fuer Desktop und Mobile

## Entwicklung

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment auf Vercel

Wenn das Projekt mit GitHub verbunden ist:

```bash
git add .
git commit -m "Update portfolio"
git push
```

Wenn du direkt mit der Vercel CLI deployen willst:

```bash
vercel deploy --prod
```
